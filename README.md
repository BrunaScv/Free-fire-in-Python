# EzFIre-in-Python
Esse projeto foi pensado para o publico do jogo mobile "Free Fire", produzido pela empresa Garena em 2017. A sua função é facilitar o aprendizado de novos jogadores. Os introduzindo a mecânicas fundamentais para a evolução dos jogadores. Sendo essas: As armas do jogo e seus atributos, dano, velocidade e alcance, temos também as habilidade dos personagens e a descrição do carregamento. Com todos esses dados sendo utilizados para adequar o jogador em 3 modos ATAQUE,DEFESA e SUPORTE.
